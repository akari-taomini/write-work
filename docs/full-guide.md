# 写卡工作台 · 0.7.1 本地改造版

本版在原作者的 0.6.0 基础上扩充，保留原作者署名与项目地址，未向上游发布。

## 0.7.1 使用说明

- 扩展设置使用酒馆原生折叠栏与箭头，展开“写卡工作台”后点击“打开写卡工作台”。栏内可开关“在魔法棒菜单显示入口”，设置保存在当前酒馆账号中，刷新后保留。
- 手机收起后的羽毛入口跟随可见视口定位；支持时使用浏览器顶层显示，避免被其他面板盖住，并使用内置图标。旧版 WebView 保留固定定位方式。
- 角色卡与独立世界书分组勾选，分别支持全选、清空和搜索后的选择；搜索不会清除隐藏资源的已选状态。首次默认局部模式，勾选资源会切回局部模式。已有保存的模式与规则继续保留。
- 默认公开示例为“顾北辰 → 沈辞”；源码、测试样例和公开包仅使用通用示例，不包含个人替换记录、真实资料扫描结果或浏览器保存的规则。
- 手机输入控件字号统一继承主题，字体使用 `em`；相关 padding、margin、gap 改为 `em`。移除原来的 `max(16px, 1em)` 下限。
- “前端正则设计”、创作工具和内容定位只滚动工作台内部，不再调用会滚动外层页面的 `scrollIntoView()`。设计器不再参与内容区的压缩，面板边界不允许内容外溢。预览仍在无脚本权限的 sandbox iframe 内。
- 新增“批量替换”：多条规则、范围组合、局部资源选择、逐处差异、取消匹配、规则组合保存、扫描取消、文件备份及冲突回滚。

### 本地模块

前端位于 `data/default-user/extensions/write-work`；配套服务端插件位于 `plugins/writer-workbench-batch`。当前安装使用 `default-user` 中的共享模块。两部分需要一起更新，不能只复制前端到其他用户后删除原共享模块。

在根目录 `config.yaml` 中启用 `enableServerPlugins: true`，然后重启酒馆。模块挂载在 `/api/plugins/writer-workbench-batch`，沿用酒馆已有的用户上下文与请求校验，不单独启动网络服务，不依赖模型或在线 API。界面显示模块未加载时请检查这一步。

### 批量替换步骤

1. 先保存原编辑器中的修改，打开工作台的“批量替换”。首次范围为空，不会自动扫描或执行。
2. 编辑左侧查找词、右侧替换词。替换词留空表示删除；可以保存常用组合。“顾北辰 → 沈辞”仅为可编辑示例。
3. 勾选作用范围。局部模式在下方分别勾选角色卡和独立世界书，或点击各组的“全选本组”“清空本组”；搜索后按钮仅影响当前筛选结果，其他已勾选项保持原样。角色卡内嵌世界书归所属角色卡。只有勾选聊天作用范围时，所选角色的聊天分支才会纳入。同名 Persona 按头像 ID 区分。全局模式处理所选作用范围内的全部资源，下方的局部勾选不会限制它；勾选任一资源会自动切回局部模式。
4. 点击“扫描匹配”，查看文件数、每条规则及每类范围的次数。展开文件查看字段路径、位置和差异；可以取消整文件或单处匹配。搜索与筛选不会自动取消隐藏结果的选择。
5. “执行替换…”会显示本次文件数和匹配数，再点击“确认备份并执行”。请暂停其他标签页、设备和编辑器的写入。工作台尚有未写入草稿或正在生成回复时会阻止执行。
6. 执行成功后自动重新载入酒馆，避免旧的内存缓存再次覆盖数据。通过“查看备份与恢复”检查结果、下载完整备份 ZIP 或回滚。

差异预览的上下文会合并所有已勾选的替换；取消其中一处时，上下文和统计同步更新。聊天当前正文与内容相同的当前候选回复作为一处逻辑匹配同步更新；角色卡标准 V1/V2 兼容字段也同步维护，预览中会显示同步路径。

### 数据边界

- 只识别当前用户数据目录中的 settings、角色卡、聊天与群聊、世界书、各类预设及 `user/files` 中明确选择的文本资料。包括不再与当前角色卡关联的独立聊天目录。不会扫描源码、第三方插件数据、缓存、日志、备份或依赖目录。
- Persona 的身份键、头像、连接与世界书引用不改名；角色自身姓名、世界书文件名、资源文件名、条目 ID、提示词编号、顺序与触发参数不替换。提示词管理器的自动注入占位条目跳过。
- 角色卡支持结构通过验证的 PNG 双数据块和 JSON。保留图像数据、额外 PNG 数据块及各版本中的未知字段；存在已识别字段冲突时跳过并显示原因，不强行统一版本。
- 其他文件限 `user/files` 下显式选中的 UTF-8 TXT、JSON、YAML。JSON/YAML 还需填写允许修改的路径，例如 `[["content"],["entries","0","content"]]`。不递归替换未知字符串，不接受客户端提供的任意磁盘路径。第三方扩展专用数据需要后续单独增加适配器。
- 原文、最长匹配优先、同长度规则顺序、非级联替换；重复查找词拒绝执行，循环关系会提示。替换后的正则查找表达式还会校验语法。
- 一次扫描最多十万处匹配，单文件最多 64 MB；执行前估算替换扩张与整批 256 MB 的数据预算，超过时需缩小范围。结果分页每次 100 处。扫描匹配分段让出执行权，允许取消。
- 扫描和预览只读取。写入前对整批文件做哈希复核、完整备份和备份校验；临时文件验证后替换原文件，记录每个文件的提交状态。JSON/JSONL 仅改选中的字符串 token，保留无关字节、换行、格式、数字与消息结构。
- 备份位于 `backups/writer-workbench/<编号>`。清单记录原路径、备份文件、修改前后 SHA-256、修改时间、规则、范围、次数和逐文件状态。单文件提交不等于跨文件原子事务；中断后可以依据清单与实际哈希恢复。通常失败会自动恢复已提交文件；出现新改动或恢复失败时保留现场并明确报告。
- 恢复前检测修改后的哈希。存在新变化时先报告冲突，不写入任何文件；可以选择“保留冲突文件，仅恢复其余文件”。回滚也保留修改后版本。请勿手工编辑备份清单。
- 文件哈希检查无法代替所有外部程序的排他锁；执行期间须暂停其他客户端的编辑。此版本只验证了本地 SillyTavern 1.19.0，TauriTavern 的原生文件接口尚未验证，不宣称直接兼容。

### 验证范围

自动测试覆盖原有替换与撤回、新的多规则与重叠处理、七个同名 Persona、聊天分支、逐处排除、UTF-8/BOM/CRLF、无关数字与字段保留、PNG 图像与双版本数据、备份失败、提交失败自动恢复、回滚冲突、备份损坏、路径越界与目录联接、扫描取消及约 13 MB 聊天。浏览器使用原生酒馆 CSS 与临时资料检查入口、设计器隔离、完整扫描/执行/恢复流程和手机字体缩放。未在真实身份资料上执行改名，也未连接模型 API。原主题与真实 iPhone 的键盘交互仍需使用时复核。

直接在 SillyTavern 里写人设、开场白、世界书和预设提示词。API 使用酒馆现有连接，无需另外填写地址和密钥。

### 状态栏使用步骤

1. 顶部搜索并绑定要写的角色卡，无需打开它的聊天。
2. 进入“局部正则”，选择已有条目，或点击“新增”。
3. 修改查找表达式，在正文框写替换 HTML/CSS；新增条目自带 `<status>…</status>` 示例。
4. 在“测试文本”粘贴模型可能输出的原文，观察实时预览；必要时切到“直接预览 HTML”单独看排版。
5. 点击“按意见修改代码”，输入例如“改成两列，手机自动换行，保留捕获组”；AI 返回后检查并替换到草稿，预览会更新。
6. 点击“写入酒馆”，保存到绑定卡的局部正则。是否允许这张卡的局部正则在实际聊天中运行，仍在酒馆原正则面板确认。

预览支持 HTML/CSS，不执行 JavaScript，不接入酒馆助手或变量系统；因此并非所有状态栏脚本都能在这里完整运行。它测试当前单条替换，不模拟多条正则串联、触发位置、深度或 Markdown 渲染。支持数字／命名捕获组、`{{match}}`、裁剪文字和基本 `{{char}}`／`{{user}}` 宏；其他宏需替换成实际值测试。AI 接收代码、测试文本与文字意见，不会自动获取预览截图。应等当前聊天回复结束后再生成。

0.3.1 搜索与退出：

- 当前世界书条目、自定义预设条目、备选开场白可以删除；删除仅改变草稿，支持“更多操作 → 撤回”，写入酒馆后生效。预设删除同步移除所有组中的引用。固定角色字段、第一开场白和内置提示词保留，仍可编辑正文或停用相应提示词。
- 退出提醒提供“不保存并退出”：放弃列出的对象尚未写入的修改，能读取时使用酒馆当前版本，无法读取时退回最后载入的基础版本，不向酒馆写入。已写入的内容不会撤销；备注、AI 输出、创作工具结果和已有历史版本保留。本地更新失败会说明失败，并允许返回编辑或保留退出。

0.3.0 条目整理：

- 搜索条目标题和正文；空格分开的关键词须同时命中。搜索不会重置正在编辑的正文或选区，预设勾选项在切换搜索词后保留。
- 聊天补全预设支持多选导出条目包，导入另一个预设时生成新编号，不覆盖已有条目。保留正文、角色、深度等设置及导出时所选组的启用状态；原生内置提示词导入为普通副本，自动注入占位条目不能打包。
- “指定位置 / 中间插入”支持在目标条目前、后或末尾新建、移动、导入。预设顺序只调整所选组；世界书只调整显示顺序，保留注入顺序数值。
- 退出工作台时列出本次打开过、尚未写入酒馆的草稿；区分本地已备份与备份失败，可以返回编辑或继续退出。刷新或离开页面时也请求浏览器原生提醒；手机强制关闭浏览器等情形不保证触发系统提示，因此仍会随编辑自动备份。
- 世界书页面可直接创建整本世界书，创建前检查名称和同名书。创建会立即保存一本空书，后续条目仍需点击“写入酒馆”；不会自动更换角色绑定。

预设条目搬家：搜索 → 展开“多选导出 / 导入条目”勾选 → 导出 → 切换“编辑对象”到目标预设 → 选择预设组及插入位置 → 导入条目包 → 检查后写入酒馆。可用“撤回”恢复导入前的草稿。条目包是工作台专用格式，请使用工作台内的“导入条目包”，不是酒馆原生完整预设导入按钮；底部“导入草稿”仍用于同一对象的完整草稿恢复。

0.2.1 手机修复：

- 手机和矮屏改为整页滚动，编辑区、提示和按钮按顺序排列，避免多层滚动与固定底栏互相挤压；根据可视窗口调整高度，适应软键盘弹出。
- 手机用下拉框选择当前栏目或世界书条目，长标题不再把横向条目栏撑开。
- 底部保留三个常用操作：写入酒馆、AI 辅助、导出草稿；历史、撤回、导入、试聊收进“更多操作”。
- 大稿件改用 IndexedDB 存储，避免整本世界书和历史副本挤占 localStorage 的小容量配额。旧稿按需迁移，确认新存储写入成功后才移除对应旧记录，不清理酒馆或其他插件的数据。
- 本地备份失败时仍允许手动写入酒馆，并分别说明正式保存与本地备份的状态。错误提示区参与正常页面排版，不再遮住正文。

如果旧界面已经提示“草稿未保存”，请先在旧界面导出当前草稿，再刷新或更新。未成功保存且只在旧页面内存里的修改，刷新后无法由新版恢复。不要清除网站数据来解决此问题。

0.2.0 的改动继续保留：

- 修复扩展设置入口被原生图标按钮宽度挤成竖排的问题；按钮使用独立的整行容器和不换行文字。
- 移除工作台固定配色，按钮和输入框使用酒馆原生样式，字体、文字和底色跟随主题。工作台面板和历史面板的背景强制为 100% 不透明，切换主题时会更新。
- 手机端默认直接按意见修改整个当前栏目，不需要选字。另有按预设起草、继续修改输出稿、仅改选中文字三种方式。
- 支持读取当前聊天最新的 AI 回复，选择目标栏目后替换或追加到草稿，免去反复复制粘贴。输出稿和意见按角色自动保留，切换栏目后不会清空。

## 安装

### 通过 GitHub 安装前端扩展

在 SillyTavern 的“安装扩展”中填写 `https://github.com/akari-taomini/write-work.git`，安装完成后刷新页面。已有旧版请更新同一个扩展，不要同时安装两份。仓库根目录必须直接包含 `manifest.json`、`index.js`、`style.css` 等文件。

也可手动将仓库根目录的前端源码放到酒馆当前用户的扩展目录 `data/default-user/extensions/write-work/`（以实际用户名或所选数据目录为准）。打开扩展设置中的“写卡工作台”即可使用。

### 批量替换服务端模块（需要单独安装）

本仓库同时附带 `plugins/writer-workbench-batch/`，该文件夹位于 **仓库内** 不代表 SillyTavern 会自动加载它。使用服务器端批量替换时，请将它复制到 **酒馆安装根目录的** `plugins/writer-workbench-batch/`；确保扩展源码能在 `data/default-user/extensions/write-work/src/batch/batch-server.js` 路径找到（如使用其他用户目录或版本，请先核对实际路径与导入语句），在酒馆 `config.yaml` 中启用 `enableServerPlugins: true`，重启酒馆。

其他编辑功能不需要额外的 Node 安装步骤。若酒馆由托管平台运营，需由有权限的人部署服务端插件。本项目面向 SillyTavern，不是 TAVO 插件。

## 日常使用

- **人物设定**：左边切换人设、性格、场景、对话示例和提示词，右边直接编辑。
- **开场白**：编辑第一条和备选开场白，也可以新增备选。
- **世界书**：选择已有世界书或新建一本，编辑标题、正文、关键词、停用、常驻和注入顺序；支持新增、复制和指定位置插入、移动。列表位置只用于整理，实际注入还受顺序数值、位置等设置影响。绑定角色及更多触发条件在酒馆原面板操作。
- **预设**：读取当前连接类型已有的预设。聊天补全预设可搜索、批量导出导入、指定位置新增或移动提示词，编辑正文、角色和各组启用状态。新增条目只加入所选预设组；其他组不自动启用。自动注入占位条目不允许直接改正文。其他连接类型只显示已有的文本提示字段，采样参数仍在酒馆原面板调整。
- **草稿**：编辑会自动保存在当前浏览器中。点击“写入酒馆”才会修改正式内容。人物设定和开场白属于同一份角色草稿；不同世界书、不同预设分别保存。
- **撤回与历史**：撤回本次打开后的编辑；历史保留最近 12 个快照，含写入前版本。恢复历史只修改草稿，还需要点击写入才生效。
- **创作备注**：随草稿保存，不写进角色卡或 AI 编辑请求。
- **导出／导入草稿**：用于备份和迁移。先打开同名、同类型的编辑对象再导入。草稿 JSON 是工作台格式，不是酒馆原生角色卡 JSON。
- **保存并新开试聊**：在人物设定或开场白页面使用，先在酒馆切到绑定的目标卡。保存后为它新开带时间戳的聊天，不删除原聊天；不会创建测试副本。世界书、局部正则和预设草稿需要分别写入。

## AI 与预设

顶部的“写作预设”读取酒馆已有预设，选择后会同步切换酒馆的当前预设。它不是独立配置槽，不会在关闭工作台后自动切回。

在“写卡与修改”中直接输入意见，例如“性格改成慢热，其他不变”。默认修改当前栏目的全文，即使编辑器残留了选区，也不会意外只改几个字。需要精确局部修改时再手动选择“只修改选中的文字”。

常用写卡流程：

1. 顶部选择你已有的写卡预设。
2. 选择“按写卡预设起草新内容”，写构思并生成；也可以点击“读取聊天最新回复”，取回刚才在酒馆里生成的稿子。
3. 不满意就切换到“继续修改下面的输出稿”，直接写修改意见。也可以手动编辑输出稿。
4. 切换到人物设定、开场白、世界书或预设，选择具体编辑对象；输出稿仍然保留。
5. 在“放到哪里”选择栏目，选择替换或追加，点击“放入该栏草稿”。放入的是整份输出稿，不会自动识别或拆分任意预设的格式；需要分段时先编辑输出框。
6. 查看草稿，点击“写入酒馆”正式保存。放错栏目可以撤回。

写作意见和输出稿单独保存在当前浏览器，按角色区分。原有“导出草稿”导出的是已放入栏目的内容及备注；需要导出输出稿时先放入相应草稿。润色、扩写、精简按钮也会遵循当前选择的写作方式。

AI 优先通过酒馆的普通消息生成接口运行，沿用当前连接、模型与参数，把当前启用的预设文字作为创作参考。旧版栏目 AI 辅助会附带最近聊天文字；新创作工具与正则设计不附带其他角色聊天。旧酒馆接口不足时使用原后台生成方式。工作台不会另存 API 密钥；每次生成会使用当前 API 的额度。若预设强调角色扮演而不愿编辑，可切换到已有写作预设。生成时可点击“停止生成”。

“预设”标签页是你正在修改的作品；顶部的“写作预设”是 AI 当前使用的配置。保存预设作品会让酒馆同步选中它。

## 保存与兼容性

草稿和历史保存在当前网站、当前账号命名空间下的 IndexedDB 中，不自动跨设备同步；浏览器不支持 IndexedDB 时回退到旧存储。清除网站数据会删除本地草稿；需要长期保存时导出备份。写入完成前显示“正在保存”，事务确认后才显示“草稿已保存”。本地保存失败会明确报错，仍可导出或手动写入酒馆。浏览器隐私限制或设备磁盘空间不足仍可能导致存储失败。

角色卡保存只提交改动字段；世界书与预设保留未编辑的数据。保存前重新读取并比较：不同字段的修改可以合并，同一字段同时变化会停止写入。冲突时可以先导出草稿，再点击“保留历史并重新载入酒馆版本”，原草稿保留在历史中。

当前版本为 0.6.0，接口按已查阅的 SillyTavern 官方 release 源码实现。本次完成创作工具流程、正则原始文本预览、标题编辑、预设变动后退出及无 assistant 预填充请求的针对性检查，未跑完整测试套件。旧版或修改版酒馆可能缺少所需接口；尚未在你的实际酒馆、手机浏览器和真实 API 上联调，模型的文本质量和格式遵循仍需实际使用确认。

自动化检查覆盖世界书旧接口兼容、新建同名保护、绑定另一张卡后保存局部正则、不切换聊天、未绑定入口、HTML 预览结构、正则捕获组及真实 Worker 超时终止，以及原有搜索、批量导入、撤回、冲突保护、移动端样式和大稿本地保存。模拟 DOM 样式检查和接口模拟不等同于真实手机截图或真实酒馆端到端测试。
