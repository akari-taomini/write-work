# 写卡工作台 0.8.2

这是作者许可改造后的本地版本，保留作者信息，尚未推送至原仓库。示例为“顾北辰 → 沈辞”。包内不含用户资料、保存的规则或实际备份。

## 更新现有扩展

先保存并关闭工作台草稿及其他编辑弹窗。保留旧扩展源码备份，将本包 `data/default-user/extensions/write-work/` 的内容覆盖到当前酒馆**已有的 write-work 扩展目录**，刷新页面。避免同时安装两份。

## TauriTavern

只更新前端扩展，不安装本包 `plugins/`，不修改 `config.yaml`。使用 TT 自己的当前资料目录，切勿把 PC SillyTavern 的资料目录配置成 TT 的替代目录。移动设备请通过 TT 支持的扩展安装／文件管理方式更新同一份前端源码；本包没有修改 TT 程序的安装步骤。

当前已在 Windows TT 2.4.0 实测：User 身份、聊天记录、角色卡、世界书可扫描、预览、备份、替换和恢复。手机及其他系统尚未实测，不能视为全平台验证通过。细节见 [TT 适配与实测说明](TT适配与实测说明.md)。

## PC SillyTavern

前端继续位于 `data/default-user/extensions/write-work/`。配套模块在酒馆根目录 `plugins/writer-workbench-batch/`，沿用原安装方式；`config.yaml` 的 `enableServerPlugins: true` 仅适用于此宿主。插件通过相对路径读取默认用户目录下的共享替换模块，请保留该位置，其他用户安装应核对原插件导入路径。

原服务端引擎保持不变，本次只增加宿主选择与 TT 前端适配。不要把文件复制到业务资料目录的角色卡、聊天、世界书或设置文件上。

## 验证

PC 及 TT 保护逻辑自动化回归 49 项通过。Windows TT 实机对 5 份实验资源、15 处匹配完成了真实读写、逐处预览、备份失败阻止提交、保存成功后模拟响应中断的回退、ZIP 导出／导入、恢复与冲突保护。TT 数据接口不支持跨资源原子事务，执行时暂停其他编辑和同步。
