# 写卡工作台 · 0.6.0

直接在 SillyTavern 里写人设、开场白、世界书和预设提示词。API 使用酒馆现有连接，无需另外填写地址和密钥。

## 这次更新

查找替换范围：

- 打开“查找替换”，可选择“当前条目”“当前预设所有条目”或“当前世界书所有条目”（随正在编辑的对象显示），再点击“全部替换”。批量范围仅限当前打开的这份预设或世界书，包含搜索隐藏、停用及未加入当前预设组的条目，跳过酒馆自动注入的占位条目。

- 预设条目标题改为输入时更新，避免编辑标题时重建输入框。放弃并退出不再依赖预设仍存在：能读取时使用酒馆新内容，无法读取时退回最后载入的基础版本，只丢弃本地修改，不写回酒馆。退出前不重绘可能失效的旧条目，避免卡住弹窗；本地存储失败仍提供保留并退出的选择。
- 前端正则设计结果改成“查找表达式”和“替换内容”两个原始文本框，直接复制到酒馆即可。模型按分段标记返回原文，无需用户处理 JSON 转义；已有 JSON 草稿仍兼容。手机及局域网 HTTP 提供复制／全选回退，仍支持实时预览、采用和导出。
- 优先使用酒馆 `generateRaw` 普通 user 消息，不添加 assistant 预填充；将当前已启用预设提示词作为参考文本带入。新创作工具和正则设计不带当前其他角色的聊天历史。旧酒馆缺少此接口时保留后台生成回退，其原有预设兼容限制可能仍存在。所有生成沿用当前连接、模型及采样参数，不保存密钥，也不自动切换聊天或参考预设。

快速使用：打开“创作工具” → 选择工具 → 填要求并生成 → 编辑结果或提修改意见 → 采用到绑定角色草稿／导出角色卡 → 必要时点击“写入酒馆”。生成格式异常时原文会保留，可自行补全或重新生成。

### 状态栏使用步骤

1. 顶部搜索并绑定要写的角色卡，无需打开它的聊天。
2. 进入“局部正则”，选择已有条目，或点击“新增”。
3. 修改查找表达式，在正文框写替换 HTML/CSS；新增条目自带 `<status>…</status>` 示例。
4. 在“测试文本”粘贴模型可能输出的原文，观察实时预览；必要时切到“直接预览 HTML”单独看排版。
5. 点击“按意见修改代码”，输入例如“改成两列，手机自动换行，保留捕获组”；AI 返回后检查并替换到草稿，预览会更新。
6. 点击“写入酒馆”，保存到绑定卡的局部正则。是否允许这张卡的局部正则在实际聊天中运行，仍在酒馆原正则面板确认。

预览支持 HTML/CSS，不执行 JavaScript，不接入酒馆助手或变量系统；因此并非所有状态栏脚本都能在这里完整运行。它测试当前单条替换，不模拟多条正则串联、触发位置、深度或 Markdown 渲染。支持数字／命名捕获组、`{{match}}`、裁剪文字和基本 `{{char}}`／`{{user}}` 宏；其他宏需替换成实际值测试。AI 接收代码、测试文本与文字意见，不会自动获取预览截图。应等当前聊天回复结束后再生成。

## 安装

1. 解压安装包，找到 `sillytavern-writer-workbench` 文件夹。
2. 把整个文件夹放到酒馆安装目录的 `public/scripts/extensions/third-party/` 下。
3. 确认最终路径为 `public/scripts/extensions/third-party/sillytavern-writer-workbench/manifest.json`，不要多套一层文件夹。
4. 刷新酒馆页面。在扩展设置中点击 **✎ 写卡工作台**，或从聊天输入框旁的扩展菜单进入。
5. 打开工作台，在顶部搜索并绑定要编辑的角色卡；无需切换当前聊天。

这是手动安装包，不需要安装 Node 依赖、不需要编译。仓库地址为 `https://github.com/akari-taomini/write-work.git`，可用于酒馆“安装扩展”；仓库版本取决于作者已上传的文件，本地安装包更新不等于已同步仓库。不要同时装两份扩展。

如果酒馆由托管平台运营，需要通过平台的文件管理器安装，或让管理员放入上述目录。此扩展面向 SillyTavern，不是 TAVO 插件。

## 日常使用

- **人物设定**：左边切换人设、性格、场景、对话示例和提示词，右边直接编辑。
- **开场白**：编辑第一条和备选开场白，也可以新增备选。
- **世界书**：选择已有世界书或新建一本，编辑标题、正文、关键词、停用、常驻和注入顺序；支持新增、复制和指定位置插入、移动。列表位置只用于整理，实际注入还受顺序数值、位置等设置影响。绑定角色及更多触发条件在酒馆原面板操作。
- **预设**：读取当前连接类型已有的预设。聊天补全预设可搜索、批量导出导入、指定位置新增或移动提示词，编辑正文、角色和各组启用状态。新增条目只加入所选预设组；其他组不自动启用。自动注入占位条目不允许直接改正文。其他连接类型只显示已有的文本提示字段，采样参数仍在酒馆原面板调整。
- **草稿**：编辑会自动保存在当前浏览器中。点击“写入酒馆”才会修改正式内容。人物设定和开场白属于同一份角色草稿；不同世界书、不同预设分别保存。
- **撤回与历史**：撤回本次打开后的编辑；历史保留最近 12 个快照，含写入前版本。恢复历史只修改草稿，还需要点击写入才生效。
- **创作备注**：随草稿保存，不写进角色卡或 AI 编辑请求。
- **导出／导入草稿**：用于备份和迁移。先打开同名、同类型的编辑对象再导入。草稿 JSON 是工作台格式，不是酒馆原生角色卡 JSON。
- **保存并新开试聊**：在人物设定或开场白页面使用，先在酒馆切到绑定的目标卡。保存后为它新开带时间戳的聊天，不删除原聊天；不会创建测试副本。世界书、局部正则和预设草稿需要分别写入。

## AI 与预设

顶部的“写作预设”读取酒馆已有预设，选择后会同步切换酒馆的当前预设。它不是独立配置槽，不会在关闭工作台后自动切回。

在“写卡与修改”中直接输入意见，例如“性格改成慢热，其他不变”。默认修改当前栏目的全文，即使编辑器残留了选区，也不会意外只改几个字。需要精确局部修改时再手动选择“只修改选中的文字”。

常用写卡流程：

1. 顶部选择你已有的写卡预设。
2. 选择“按写卡预设起草新内容”，写构思并生成；也可以点击“读取聊天最新回复”，取回刚才在酒馆里生成的稿子。
3. 不满意就切换到“继续修改下面的输出稿”，直接写修改意见。也可以手动编辑输出稿。
4. 切换到人物设定、开场白、世界书或预设，选择具体编辑对象；输出稿仍然保留。
5. 在“放到哪里”选择栏目，选择替换或追加，点击“放入该栏草稿”。放入的是整份输出稿，不会自动识别或拆分任意预设的格式；需要分段时先编辑输出框。
6. 查看草稿，点击“写入酒馆”正式保存。放错栏目可以撤回。

写作意见和输出稿单独保存在当前浏览器，按角色区分。原有“导出草稿”导出的是已放入栏目的内容及备注；需要导出输出稿时先放入相应草稿。润色、扩写、精简按钮也会遵循当前选择的写作方式。

AI 优先通过酒馆的普通消息生成接口运行，沿用当前连接、模型与参数，把当前启用的预设文字作为创作参考。旧版栏目 AI 辅助会附带最近聊天文字；新创作工具与正则设计不附带其他角色聊天。旧酒馆接口不足时使用原后台生成方式。工作台不会另存 API 密钥；每次生成会使用当前 API 的额度。若预设强调角色扮演而不愿编辑，可切换到已有写作预设。生成时可点击“停止生成”。

“预设”标签页是你正在修改的作品；顶部的“写作预设”是 AI 当前使用的配置。保存预设作品会让酒馆同步选中它。

## 保存与兼容性

草稿和历史保存在当前网站、当前账号命名空间下的 IndexedDB 中，不自动跨设备同步；浏览器不支持 IndexedDB 时回退到旧存储。清除网站数据会删除本地草稿；需要长期保存时导出备份。写入完成前显示“正在保存”，事务确认后才显示“草稿已保存”。本地保存失败会明确报错，仍可导出或手动写入酒馆。浏览器隐私限制或设备磁盘空间不足仍可能导致存储失败。

角色卡保存只提交改动字段；世界书与预设保留未编辑的数据。保存前重新读取并比较：不同字段的修改可以合并，同一字段同时变化会停止写入。冲突时可以先导出草稿，再点击“保留历史并重新载入酒馆版本”，原草稿保留在历史中。

当前版本为 0.6.0，接口按已查阅的 SillyTavern 官方 release 源码实现。本次完成创作工具流程、正则原始文本预览、标题编辑、预设变动后退出及无 assistant 预填充请求的针对性检查，未跑完整测试套件。旧版或修改版酒馆可能缺少所需接口；尚未在你的实际酒馆、手机浏览器和真实 API 上联调，模型的文本质量和格式遵循仍需实际使用确认。

自动化检查覆盖世界书旧接口兼容、新建同名保护、绑定另一张卡后保存局部正则、不切换聊天、未绑定入口、HTML 预览结构、正则捕获组及真实 Worker 超时终止，以及原有搜索、批量导入、撤回、冲突保护、移动端样式和大稿本地保存。模拟 DOM 样式检查和接口模拟不等同于真实手机截图或真实酒馆端到端测试。
