# 写卡工作台（Writer Workbench）

适用于 SillyTavern 的写卡、世界书、开场白与预设编辑扩展。当前版本 **0.7.1**。

在原作者 0.6.0 基础上扩充。历史更新与原作者信息见 [旧版完整说明](docs/full-guide.md)。

## 一键安装

在 SillyTavern（或支持标准前端扩展的 TauriTavern）的 **扩展 → 安装扩展** 中填写：

```text
https://github.com/akari-taomini/write-work.git
```

安装后刷新并从扩展设置打开「写卡工作台」。无需复制服务器 `plugins` 文件夹，也无需修改 `config.yaml`。

> **兼容范围**：此仓库只提供前端扩展。TauriTavern 可安装前端扩展，但每项功能的底层接口兼容性仍须实际验证；尤其不是所有 SillyTavern 接口都必然在 TT 中实现。不要将「可安装」当成已完成 TT 全功能实测。

## 主要功能

- **人物设定、开场白、世界书、预设与局部正则**：编辑、草稿保存、写回酒馆
- **AI 辅助、创作工具、前端正则设计**
- **编辑器查找与全部替换**：当前条目、当前预设全部条目或当前世界书全部条目；不需要服务端插件
- **草稿历史、撤回、导入、导出与冲突保护**

这里的「全部替换」是通过现有前端接口处理所选预设/世界书的内容，**不是扫描酒馆磁盘中的所有角色、聊天和历史文件**。

此前实验性的 Node.js 服务端跨文件批量替换只适用于特定 SillyTavern 部署，无法作为 TauriTavern 通用解决方案。为保证普通用户直接安装，已从默认仓库移除；原代码可在 Git 历史中找到。

## 目录

```text
write-work/
├── manifest.json          # 前端扩展入口配置
├── index.js               # 浏览器主入口
├── style.css              # 样式
├── src/
│   ├── app/               # 酒馆交互、布局、存储
│   ├── core/              # 搜索、替换、预设和正则基础工具
│   └── features/          # 创作工具、前端正则设计
├── tests/                 # 编辑器测试
├── docs/                  # 目录说明与历史文档
└── package.json
```

阅读 [文件职责与开发说明](docs/project-structure.md)。

## 开发测试

在支持 Node.js 的开发环境中运行 `npm test`。静态导入路径核对不代表真机兼容性测试；正式使用前请备份重要人物卡和世界书。
